## 🌟 Overview

**AUREX** is an intelligent healthcare platform designed to detect **pre-symptomatic health risks** before they become serious problems.

Instead of reacting to illness after symptoms appear, AUREX focuses on **prediction, prevention, and personalized health intelligence**.

The platform analyzes health data such as:

- Age
- BMI
- Sleep habits
- Physical activity
- Working hours
- Lifestyle patterns

Using these inputs, AUREX generates:

✅ Personalized risk predictions  
✅ Preventive health recommendations  
✅ Wellness tracking insights  
✅ Early warning alerts  
✅ Smarter lifestyle suggestions

> ⚠️ **Disclaimer:** AUREX is an experimental MVP and **not a medical device**. It should not replace professional medical advice.

# 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/amrrish27/Aura-Health.git
```

Go into project directory:

```bash
cd Aura-Health
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

---

# 🔧 Environment Variables

Create a `.env` file in the root directory.

Example:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```
